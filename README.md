# MOMO - Smart MOMO V2 – Smart Animal Scanner

Project Name: MOMO
Version: V2
Platform: Android
Project Type: Smart Animal Scanner

1. Project Overview

MOMO is an Android application designed to work with a smart animal scanning probe.

2. Main Features

- Animal registration and management.
- Animal information records.
- Examination history and follow-up notes.
- Arabic and French interface.
- Smart probe connection planned through Wi-Fi and USB-C.
- Support for different animal species, with the ability to add new species.

3. Hardware Integration

The project is designed for future integration with a smart scanning probe.

Actual sensor readings and probe communication are not yet implemented.

4. Development Status

Early Android prototype. The application currently supports basic animal records and local data storage.

5. Future Development

- Wi-Fi and USB-C communication.
- Sensor data acquisition.
- Probe calibration.
- Examination reports.
